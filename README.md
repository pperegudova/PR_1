# Эмулятор оболочки ОС (Этап 1-3, Вариант 13)

---

## 1. Общее описание

Программа имитирует работу командной строки UNIX-подобной ОС через 
графический интерфейс (GUI) на базе библиотеки `Tkinter`. На Этапе 3 
реализована полноценная виртуальная файловая система (VFS), работающая 
исключительно в оперативной памяти.

### Основные особенности и реализованные требования Этапа 1:
- Графический интерфейс пользователя (GUI).
- Парсер командной строки поддерживает разбор аргументов в кавычках.
- Реализован вывод сообщений об ошибках (неизвестная команда, 
  неверные аргументы).
- Реализованы команды-заглушки: `ls`, `cd`.
- Реализована команда завершения работы: `exit`.

### Основные особенности и реализованные требования Этапа 2:
- Разбор аргументов командной строки (`--vfs`, `--script`, `--config`).
- Парсинг конфигурационного файла формата TOML (`load_toml_config`).
- Приложение считывает параметры из командной строки и конфигурационного файла.
- Логика приоритета: параметры командной строки имеют приоритет над файлом конфигурации.
- Обработка ошибок при чтении файла конфигурации.
- Выполнение стартового скрипта с отображением команд и результатов вывода в GUI, с автоматической остановкой при первой возникшей ошибке.

### Основные особенности и реализованные требования Этапа 3:
- Виртуальная файловая система (VFS) хранится исключительно в памяти.
- Источник VFS — XML-файл с бинарными данными в формате base64.
- Реализована структура дерева VFS с родительско-дочерними связями.
- Реализована загрузка VFS из XML с обработкой ошибок (файл не найден, 
  неверный формат).
- Реализована полноценная логика команд `ls` и `cd` для навигации по VFS.
- Поддержка абсолютных и относительных путей, включая `..` и `.`.
- Созданы тестовые варианты VFS: минимальный, с файлами, с глубокой 
  вложенностью (3 уровня).
- Заголовок окна формируется динамически на основе имени файла VFS.

## 2. Описание всех функций и настроек

### Константы
В модуле `src/main.py` вынесены следующие настройки:
* `UI_WIDTH` (60) — ширина текстовой области GUI в символах.
* `UI_HEIGHT` (20) — высота текстовой области GUI в строках.
* `PROMPT` ("$ ") — символ приглашения к вводу, отображаемый в истории команд.

### Описание функций (`src/main.py`)

- **`_parse_xml_node(xml_node, parent=None)`**  
  Рекурсивно строит дерево VFS из XML-узла. Корневой тег `<vfs>` и теги 
  `<dir>` интерпретируются как директории. Бинарные данные декодируются 
  из base64.

- **`load_vfs(xml_path)`**  
  Загружает VFS из XML-файла в память. Возвращает корневой узел дерева 
  или `None` при ошибке (файл не найден, неверный формат).

- **`parse_command(raw_input: str) -> list`**  
  Разбирает строку ввода пользователя на список аргументов с помощью 
  модуля `shlex`. Корректно обрабатывает кавычки. В случае синтаксической 
  ошибки (например, незакрытая кавычка) возвращает `None`.

- **`parse_cli_args() -> argparse.Namespace`**  
  Считывает флаги командной строки: `--vfs` (путь к VFS), `--script` (путь к стартовому скрипту) и `--config` (путь к файлу конфигурации TOML).

- **`load_toml_config(path: str) -> dict`**  
  Считывает и парсит простейший TOML-файл конфигурации. Возвращает словарь с ключами или `None`, если файл не найден либо возникла ошибка чтения.

- **`merge_configs(toml_cfg: dict, cli_args: argparse.Namespace) -> dict`**  
  Объединяет настройки. Обеспечивает приоритет параметров командной строки над значениями из конфигурационного файла TOML.

- **`ShellEmulator.__init__(root: tk.Tk)`**  
  Инициализирует графический интерфейс Tkinter, устанавливает заголовок 
  окна и регистрирует поддерживаемые команды (`ls`, `cd`, `exit`).

- **`ShellEmulator._setup_ui()`**  
  Создает текстовое поле с прокруткой (`ScrolledText`) для вывода результатов 
  и однострочное поле ввода (`Entry`) для команд.

- **`ShellEmulator._register_commands()`**  
  Регистрирует словарь поддерживаемых команд (`ls`, `cd`, `exit`).

- **`ShellEmulator._print_debug_info()`**  
  Выводит в окно эмулятора отладочные сообщения о загруженных путях VFS и скрипта.

- **`ShellEmulator._run_startup_script()`**  
  Считывает стартовый скрипт пошагово, имитирует пользовательский ввод с символом `$ `, запускает команды на исполнение и останавливает работу скрипта при первой ошибке.

- **`ShellEmulator._write_output(text: str)`**  
  Безопасно добавляет текст в текстовое поле вывода и прокручивает его вниз.

- **`ShellEmulator._on_enter(event)`**  
  Обработчик нажатия клавиши `Enter` в поле ввода. Считывает команду, 
  отображает ее в консоли и передает на выполнение.

- **`ShellEmulator._resolve_path(path_str)`**  
  Ищет узел VFS по относительному или абсолютному пути. Поддерживает 
  навигацию с использованием `..` (родительская директория) и `.` 
  (текущая директория).

- **`ShellEmulator._execute(raw_input: str)`**  
  Передает строку ввода в `parse_command`. Проверяет наличие ошибок разбора 
  и вызывает соответствующий обработчик команды или выводит сообщение 
  об ошибке.

- **`ShellEmulator._ls_cmd(name: str, args: list) -> bool`**  
  Выводит содержимое указанной директории VFS. Для каждой записи отображает 
  тип (d — директория, - — файл) и имя.

- **`ShellEmulator._cd_cmd(name: str, args: list) -> bool`**  
  Меняет текущую директорию в VFS. Поддерживает абсолютные и относительные 
  пути.

- **`ShellEmulator._exit_cmd(name: str, args: list)`**  
  Завершает выполнение приложения и закрывает окно Tkinter.

## 3. Описание команд для сборки проекта и запуска тестов

Проект не требует предварительной сборки и компиляции, так как написан 
на интерпретируемом языке Python 3.

### Запуск приложения

- **Запуск с файлом конфигурации TOML:**
  ```bash
  python3 main.py --config config.toml
  ```

- **Запуск с переопределением через командную строку (приоритет CLI):**
  ```bash
  python3 main.py --config config.toml --script custom_script.txt
  ```
  
- **Запуск напрямую с параметрами VFS и скрипта, содержащего все команды, реализованные до 3 этапа:**
  ```bash
  python3 src/main.py --vfs tests/vfs_deep.xml --script tests/script_stage3.txt
  ```

### Запуск модульных тестов

Для запуска автоматических тестов парсера используется встроенный 
фреймворк `unittest`:

```bash
python3 -m unittest discover -s tests
```

Запуск автоматических тестов командной строки:

```bash
bash tests/test_cli.sh
```

Запуск автоматических тестов VFS:

```bash
bash tests/test_vfs.sh
```

## 4. Примеры использования

### 1. Пример файла конфигурации (`config.toml`)

```text
vfs_path = "./tests/vfs_deep.xml"
script_path = "./tests/script_stage3.txt"
```

### 2. Выполнение стартового скрипта (`script_stage3.txt`)
**Содержимое файла `script_stage3.txt`:**
```text
ls
cd level1
ls
cd level2
cd level3
ls
cd ..
cd ..
cd ..
ls
```
**Вывод в графическом окне эмулятора при запуске (использовалась команда: `python3 src/main.py --config config.toml`):**
```text
--- Отладочный вывод ---
VFS Path: ./tests/vfs_deep.xml
Script Path: ./tests/script_stage3.txt
------------------
Запуск стартового скрипта: ./tests/script_stage3.txt
$ ls
d level1
$ cd level1
$ ls
d level2
$ cd level2
$ cd level3
$ ls
- deep_secret.txt
$ cd ..
$ cd ..
$ cd ..
$ ls
d level1
```

### 3. Остановка скрипта при первой ошибке
**Если в `script_stage3.txt` присутствует неизвестная команда или несуществующая директория:**
```text

ls
cd level2
cd level3
ls
cd ..
cd ..
cd ..
ls
cd non_existent_dir
ls /invalid/path
```
**Вывод в эмуляторе (использовалась команда: `python3 src/main.py --config config.toml`):**
